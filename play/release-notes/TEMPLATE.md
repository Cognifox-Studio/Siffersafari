# Dual-locale what’s-new template (ROI #94)

Copy into **both** `whatsnew-sv-SE` and `whatsnew-en-US` before each tag/Play upload.
Keep the same beat order; translate meaning, not word-for-word stuffing.

Constraints (Play):

- Prefer ≤ 500 characters per locale
- 3–5 short lines; no markdown
- Kid-facing first; parent trust second

## Skeleton

```
sv-SE:
• <barnsynligt 1>
• <barnsynligt 2>
• <trygghet/förälder eller polish>
• <stabilitet om relevant>

en-US:
• <child-visible 1>
• <child-visible 2>
• <trust/parent or polish>
• <stability if relevant>
```
